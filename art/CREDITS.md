# 《风停之前》美术素材

| 素材 | 作者与来源 | 授权情况 |
| --- | --- | --- |
| 小屋内外、家具、工具、织物和灯具 | 本项目原创，由 `tools/blender/build_hut.py` 生成 | 项目自产资产 |
| 木纹、旧漆和织物色彩图集，环境遮蔽和夜间光照 | 本项目原创，使用 Blender Cycles 程序材质与场景烘焙 | 项目自产资产 |
| 潮汐表、线路图、维修记录、划掉的方案、门牌和终端画面 | 本项目原创，由 `tools/blender/hut_prints.py` 绘制 | 项目自产图形；文字使用本机 Windows 字体栅格化 |
| 他、玩家、服装、骨骼与动画 | 本项目原创，由 `tools/blender/build_hut_characters.py` 生成 | 项目自产资产 |
| 海湾旧街、店招、门牌、风铃、街灯和晾衣 | 本项目原创，见 `town_street.py` 和 `town_palette.py` | 项目自产资产 |
| 木栈道、沙滩船只、旧石堤及接线盒 | 本项目原创，见 `town_dock.py` | 项目自产资产 |
| 崖壁岩层、断桥、信号站、天线塔、山林和灯塔 | 本项目原创，见 `town_storm.py` 和 `town_nature.py` | 项目自产资产 |
| 整图色彩图集和四张区域 AO | 本项目以程序生成木纹、石材、旧漆和印刷图形，再以 Blender Cycles 烘焙区域遮蔽。见 `town_palette.py` 和 `town_art.py` | 项目自产资产 |
| 杂货店奶奶、灰猫、渔夫、放风筝的小孩、邮递员 | 本项目原创，由 `town_cast.py` 构建服装、角色、动作和随蒙皮移动的顶点 AO。人形骨架沿用样片 | 项目自产资产 |

印刷品使用 Windows 提供的 SimHei 和 Consolas。成品中包含栅格化的文字。字体文件由构建机器提供。[Microsoft 字体使用说明](https://learn.microsoft.com/en-us/typography/fonts/font-faq)

Quaternius 的角色包曾作为候选。作者托管目录达到下载配额后，本轮按约定采用原创角色。成品使用的模型和动画均来自项目生成脚本。
