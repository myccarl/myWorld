# 风停之前 · 文字原型

## 在电脑上运行

在 `D:\myWorld` 下运行：

```bash
python tools/serve.py
```

然后用浏览器打开 `http://localhost:8765`。不能直接双击 `index.html`，必须通过这个本地服务打开。

这个服务会告诉浏览器"不要缓存"，所以改了台词或代码后，**刷新一下就能看到**。（如果用的是 `python -m http.server`，浏览器可能一直用旧文件，要按 Ctrl+F5 强制刷新。）端口被占用时可以换一个：`python tools/serve.py 8080`。

用手机测：手机和电脑连同一个 Wi-Fi，打开 `http://电脑的局域网IP:8765`。电脑的局域网 IP 可以在命令行里运行 `ipconfig`，看"IPv4 地址"那一行。

## 改对白（任务 Y1）

所有台词都在 `story/` 文件夹里，一个场景一个文件：

| 文件 | 场景 |
|---|---|
| `s01_dawn.js` | 清晨 · 码头 |
| `s02_town.js` | 上午 · 旧街 |
| `s03_workbench.js` | 中午 · 工作台（推理） |
| `s04_fix.js` | 下午 · 旧码头 |
| `s05_warning.js` | 傍晚 · 工作台 |
| `s06_storm.js` | 风暴 |
| `s07_station.js` | 入夜 · 信号站 |
| `s08_night.js` | 深夜 · 工作台 |
| `s09_daybreak.js` | 黎明、B 面、片尾 |
| `clues.js` | 笔记本里的线索 |
| `index.js` | 游戏名、副标题 |

每句台词长这样：

```js
['hero', '你再这样我就把你拆了卖废铁。'],
```

- 第一项是谁在说：`hero` 是他，`me` 是玩家，`narr` 是旁白，其他直接写中文名（如 `'奶奶'`）。
- **只改第二项引号里的文字**。不要删掉引号、逗号和方括号。
- 想加一句：复制一整行，粘贴在下面，改文字。
- 想删一句：删掉一整行。
- 中文引号"…"可以直接用；英文单引号 `'` 不能出现在文字里（会把句子截断）。
- 文字里的 `{callName}`、`{catName}` 之类会被替换成每位朋友的专属内容，保留原样。

改完保存，刷新浏览器就能看到。如果页面出错或变白，多半是少了逗号或引号。按 F12 打开控制台，会提示是哪个文件第几行。

## 给一位朋友做专属链接

1. 复制 `configs/default.json`，改名为一个随机串，例如 `configs/k7Qm2x.json`（只用英文字母和数字，**不要用名字**）。
2. 改里面的内容：

| 字段 | 填什么 |
|---|---|
| `callName` | 信封上写的称呼 |
| `catName` | 猫的名字 |
| `radioSong` | 奶奶收音机里放的歌 |
| `smallThing` | 一件对方会惦记的小事，要能放进"来之前我一直惦记着＿＿＿。"这句话 |
| `smallThingDone` | 一句旁白：他已经替对方把这件事办好了的样子 |
| `letter` | 信。文字写在 `content`；如果是手写扫描件，`type` 改成 `"image"`，`content` 写图片路径，例如 `"configs/k7Qm2x.jpg"` |

3. 链接是 `网址/?k=k7Qm2x`。每个链接的存档是分开的。

**这些文件里有真实的名字和信，不要上传到任何公开的地方，也不要发给 AI。**

## 3D 测试页（D1）

打开 `http://localhost:8765/world_test.html?debug`（去掉 `?debug` 就不显示帧率）。

- 手机：左半屏按下出现摇杆；右半屏拖动转镜头；右下角"跑"按住跑，"交互"暂时只弹一句提示。
- 电脑：WASD 移动，Shift 跑，E 交互，鼠标拖动转镜头。
- 右上角"高 / 中 / 低"切换画质（会刷新页面）。
- 左上角一排按钮切换八个时段（清晨、上午、中午、下午、傍晚、风暴、深夜、黎明），看光照效果，切换有 3 秒过渡。
- 用手机测时，**请记下左下角显示的帧率**（fps），在你的手机上分别试高、中、低三档。

## 3D 模式（测试中）

- 打开 `http://localhost:8765/?mode=3d`，或者在游戏的暂停菜单里点"3D 模式（测试中）"。切换后会刷新页面，正在玩的话会直接接着玩。
- 现在用的是 Codex 用 Blender 生成的小镇地图 `assets/town.glb`（灰盒）。所有场景需要的地点都已经摆进世界里。旧的测试地图还在，网址加 `?map=world_test` 可以切回去。
- 自由行走时：左上角是当前提示；走近发光的小点，右下角会出现带名字的交互键；走到街口会自动触发"去找他"。
- B 面与片尾：B 面在 3D 里逐张回放他做过的事（在当时的地点、时段，你注意到的是暖色，没注意到的是蓝灰色）；片尾是天亮的海湾，读到"灯，灭了"时台灯真的熄灭。
- 灯：标题画面是夜里海湾上那间亮着灯的小屋；信号站推门时镜头切到小镇上空，窗户按编号一盏一盏亮起来；深夜屋里只有台灯和屏幕的光，坐到他身边时镜头会非常慢地推近。
- 引导：一个场景里 90 秒没推进主线，他会远远招手；3 分钟还没找到路，他会走到你身边、再走向要去的地方等你（他不在这个场景时，只让左上角的提示闪一下）。
- 坐下：走近长椅（地图里的 `sit_` 座位），交互键变成"坐下"；点屏幕或推摇杆站起来。
- 风暴（第 6 场）：看浪时躲在礁石后面、浪退了再冲；断桥按住按钮；扛电池上坡走得慢。风暴里下雨、偶尔打闪。暂停菜单里可以关掉"镜头晃动"。
- 暂停菜单打开"辅助模式"后，自由行走时多一个"走到下一个地方"的按钮。
- 角色：他、玩家、奶奶、猫、渔夫、放风筝的小孩、邮递员都是 Codex 做的原创模型（`game/assets/characters/`）。第 2 场里渔夫在海边、小孩在沙滩上跑、邮递员在街上来回走（暂时没有台词）。
- 会动的小东西：风铃和晾衣随风摆（风暴时最大），傍晚和全镇亮灯时路灯亮，码头信号箱的红灯一直在闪，第 4 场接线盒的盖子会掀开、盖上。
- 原来的说明：角色曾经是代码拼出来的占位小人和一只猫（他、奶奶、猫、玩家）。有了真正的模型（.glb，带动画）后，放到 `assets/characters/`，在 `story/cast.js` 里把 `model` 填上文件名即可。
- 临时试另一张地图：网址加 `?map=地图名`，例如 `http://localhost:8765/?mode=3d&map=world_test`。
- 换成你自己的地图：把 `story/index.js` 里的 `map: 'world_test'` 改成你的文件名。

## 检查地图

做好（或让 Codex 做好）地图后，在 `D:\myWorld` 下运行：

```bash
node tools/check_map.mjs game/assets/town.glb
```

它会从剧情里收集所有需要的地点名字，逐场景列出地图里缺了哪些，并检查三角面、材质、窗户数量等预算。

## 测试小技巧

网址参数（可以组合，用 `&` 连起来）：

| 参数 | 作用 |
|---|---|
| `?mode=3d` / `?mode=text` | 切换 3D / 文字模式 |
| `?jump=s08_night` | 直接从某一场开始（会清掉当前进度）；也可以写到节点，例如 `s07_station/n2` |
| `?quality=high` / `medium` / `low` | 指定画质（会记住） |
| `?debug` | 3D 模式下左下角显示帧率 |

例如手机上直接看深夜工作台：`http://电脑的局域网IP:8765/?mode=3d&jump=s08_night&debug`


- 暂停菜单里可以把"文字速度"调成"瞬间"，快速走剧情。
- "辅助模式"打开后，风暴每段点一下就过。
- 想从头再来：暂停菜单里"清空存档"（点两次）。
- 想看回夜晚版的标题画面：用浏览器的无痕窗口打开。
