使用前核对了 [CMU 官网 FAQ 的 How can I use this data?](http://mocap.cs.cmu.edu/faqs.php) 及 [数据库首页使用条款](http://mocap.cs.cmu.edu/)。可复制、修改和再分发，可将动捕用于商业产品；不得直接转卖动捕数据，包括格式转换版。

| 被试 | 片段 | 官方描述与使用 | 原始来源 |

| 35 | 骨架 ASF | 以下片段共用的受试者标定骨架 | [35.asf](http://mocap.cs.cmu.edu/subjects/35/35.asf) |

帧号从 1 起算，原始数据为 120 Hz。两人共用录制区间、步相和动作约束，按各自 MPFB2 骨长与鞋形求解。半张手姿由项目制作。官网文件校验值、实机分相、脚印及实测数字见[步态交付报告](../../tools/blender/previews/R3_CMU步态/交付报告.md)。

The data used in this project was obtained from mocap.cs.cmu.edu. The database was created with funding from NSF EIA-0196217.
